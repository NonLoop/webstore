Vibe Coding Kit · Privacy Policy

最后更新：2026 年 11 月 1 日

Last updated: November 1, 2026

Vibe Coding Kit 是 AI 编程知识库、AI 对话与面试模拟助手。知识库随扩展打包、离线可读；AI 功能完全连接你自己配置的服务端点，扩展本身没有自有服务器，也不中转、不留存你的任何对话内容。

一、在你设备上处理的内容

  • AI 配置：Base URL、API Key、模型名、Temperature（仅存 chrome.storage.local，只用于向你配置的端点发起请求）
  • 对话与面试记录、每日额度计数、浏览进度与解锁状态缓存（同样仅存本地）
  • 知识库搜索与筛选在本地完成，搜索词不会上传
  • 可选 Pro 解锁经 ExtensionPay：可能在本地缓存付费/邮箱信息以便短时离线识别。银行卡信息由 ExtensionPay 及其支付服务商处理

二、AI 请求去向（请重点阅读）

  • 仅当你主动使用 AI 对话或面试模拟时，扩展会通过后台 service worker 把你该次会话的消息发送到你自行填写的 OpenAI 兼容 API 端点（例如 OpenAI、DeepSeek、Kimi 或你的自建服务）
  • 该等数据接收方由你选择并配置，受该服务商自己的隐私政策约束；本扩展不建立自有推理服务器，不复制、不分析、不留存这些请求
  • 不使用时零网络活动：知识库阅读与界面本身完全离线

三、我们不收集

  • 网页内容、表单数据或网站 Cookie（浮动小窗不读取所在页面任何内容）
  • 浏览历史、标签标题或标签 URL
  • 你的 API Key（除本地存储外从不发送往任何第三方）
  • 分析或广告标识符；界面不发起远程字体或追踪请求

四、权限说明

权限用途
storage保存 AI 配置（含 API Key，仅本地）、对话记录、额度计数与解锁缓存
activeTab在需要时读取当前标签页标题 / URL，用于面试模拟的题目情境化（仅你主动触发时）
主机权限 <all_urls>仅用于浮动小窗的注入：约 36KB、Shadow DOM 隔离的入口按钮，不读取、不记录页面内容

浮动小窗为纯界面注入：它与宿主页面被 Shadow DOM 完全隔离，除按钮本身外不采集周围任何文字、表单或 Cookie。

五、网络汇总

  • 你配置的 AI 端点——仅在你使用 AI 对话 / 面试模拟时
  • ExtensionPay（extensionpay.com）——仅在你打开购买或登录时
  • 除此之外无任何自有请求；知识库完全离线

六、数据存储与你的权利

全部数据（含 API Key 与对话记录）保存在你的设备本地，可通过清除扩展数据或卸载 Vibe Coding Kit 删除。发送到你自己 AI 端点的内容，请参照该服务商的政策行使权利。

七、未成年人

本扩展不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

八、政策更新

我们可能不时更新本政策。重大变更可能随扩展更新说明。请定期查阅本页。

九、联系我们与同意

隐私相关问题请发送邮件至 yugakhans@gmail.com，或联系 Chrome Web Store 商品页上的发布者。安装并使用 Vibe Coding Kit，即表示你同意本隐私政策；若不同意，请勿使用本扩展。

Vibe Coding Kit is an AI coding knowledge base with an AI chat and mock-interview assistant. The knowledge base ships with the extension and reads offline; the AI features connect exclusively to endpoints you configure yourself. The extension has no first-party server, and never relays or retains your conversations.

1. What we process on your device

  • AI settings: Base URL, API Key, model name, temperature (stored in chrome.storage.local only, and only used to call the endpoint you configured)
  • Chat and interview history, daily-quota counters, browsing progress and local unlock cache (local only as well)
  • Knowledge-base search and filtering run locally; search terms are never uploaded
  • Optional Pro unlock via ExtensionPay: a local paid/email cache may be kept so unlock works offline for a limited TTL. Payment card data is processed by ExtensionPay / its processors

2. Where AI requests go (please read)

  • Only when you actively use AI chat or mock interviews, the background service worker sends that session’s messages to the OpenAI-compatible endpoint you entered (e.g. OpenAI, DeepSeek, Kimi, or your own server)
  • Those recipients are chosen and configured by you and are governed by their own privacy policies. We operate no inference servers of our own and do not copy, analyze or retain these requests
  • Zero network activity otherwise: knowledge-base reading and the UI work fully offline

3. What we do not collect

  • Page content, form data, or website cookies (the floating widget never reads the host page)
  • Browsing history, tab titles, or tab URLs (beyond the on-demand use described below)
  • Your API Key (never sent anywhere except the endpoint you configured, and never to third parties)
  • Analytics or advertising identifiers; no remote font or tracking requests from the UI

4. Permissions

PermissionWhy
storageAI settings (incl. API Key, local only), chat history, quota counters and unlock cache
activeTabOptionally reading the current tab’s title / URL to contextualize interview questions — only when you trigger it
Host permission <all_urls>Used only to inject the floating widget: a ~36KB, Shadow-DOM-isolated launcher button. It does not read or record page content

The floating widget is a UI-only injection: it is fully isolated from the host page by Shadow DOM and collects no text, forms or cookies beyond the button itself.

5. Network summary

  • Your configured AI endpoint — only while you use AI chat / mock interviews
  • ExtensionPay (extensionpay.com) — only when you open purchase or login
  • No other first-party requests; the knowledge base is fully offline

6. Data storage and your rights

All data (including your API Key and chat history) stays in local storage on your device — delete it by clearing extension data or uninstalling Vibe Coding Kit. For content sent to your own AI endpoint, exercise your rights under that provider’s policy.

7. Children’s privacy

This extension is not directed to children under 13. We do not knowingly collect personal information from children.

8. Changes

We may update this policy from time to time. Significant changes may be noted with extension updates. Please review this page periodically.

9. Contact and consent

For privacy questions, email yugakhans@gmail.com or contact the publisher listed on the Chrome Web Store item page. By installing and using Vibe Coding Kit, you agree to this privacy policy. If you do not agree, please do not use the extension.
