Features

核心能力

What’s inside

记录、筛选、导出全部在本机完成。

Capture, filter and export — entirely on your device.

01

四种记录方式

Four ways to capture

选中气泡「＋ 留痕」、右键保存、弹窗手记、整段聊天粘贴拆条逐条导入。

Select-to-save bubble, context menu, popup notes, or paste a multi-person chat and import line by line.

02

本地自动识别

Local auto-detect

七种类型（承诺 / 变更 / 甩锅 / 风险 / 决定 / 认可 / 其他），以及人名、日期、金额——规则跑在本机，不联网。

Seven types (promise / change / blame / risk / decision / praise / other), plus people, dates and amounts — rule-based, offline.

03

时间线与报告

Timeline & reports

按天分组、按人筛选、星标与搜索。一键摘要，并导出 Markdown / 可打印 HTML（另存 PDF）/ JSON 备份。

Grouped by day, filter by person, stars and search. One-line summary; export Markdown, printable HTML (Save as PDF), or JSON backup.

04

隐私优先

Privacy first

无账号、无云端、无埋点。记录只存 chrome.storage.local。可选 Pro 经 ExtensionPay 解锁额度与导出。

No account, no cloud, no analytics. Records stay in chrome.storage.local. Optional Pro via ExtensionPay unlocks quotas and export.

免费版可留下有限条数；Pro 为 ExtensionPay 解锁无限记录、截图与完整导出。数据始终在你的设备上。

Free keeps a limited number of records; Pro unlocks via ExtensionPay — unlimited notes, screenshots and full export. Data stays on your device.
