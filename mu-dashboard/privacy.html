Mu Dashboard · Privacy Policy

最后更新：2026 年 10 月 24 日

Last updated: October 24, 2026

Mu Dashboard 用于展示本机系统与浏览器指标（CPU、内存、存储、显示器及相关浏览器 API）。设计目标是尽量少收集数据。

一、在你设备上处理的内容

  • 用于渲染弹窗看板与可选悬浮 HUD 的指标快照
  • 设置：语言、刷新间隔、悬浮面板偏好、可选告警阈值（chrome.storage.local）
  • 可选解锁状态经 ExtensionPay：可能在本地缓存付费/邮箱信息以便短时离线识别解锁。银行卡信息由 ExtensionPay 及其支付服务商处理——Mu Dashboard 不运营指标后端

二、我们不收集

  • 网页内容、表单数据或网站 Cookie
  • 浏览历史、标签标题或标签 URL
  • 按键或剪贴板内容
  • 本扩展自有代码中的分析或广告标识符
  • 扩展界面发起的远程字体或追踪请求（仅使用系统字体）

三、权限说明

权限用途
system.cpu / system.memory / system.storage / system.display读取看板展示的硬件指标
storage保存设置与本地解锁缓存
alarms轻量后台预热
scripting + 可选主机访问仅在你开启悬浮 HUD 时；注入封闭 Shadow 浮层，不读取页面
notifications（可选）仅在你开启桌面告警时

悬浮 HUD 默认关闭。开启时会触发 Chrome 权限提示。

四、网络

  • 仅在你打开购买或登录时访问 ExtensionPay（extensionpay.com）
  • 无其他自有遥测接口

五、数据存储与你的权利

设置与解锁缓存通过浏览器本地存储 API 保存在你的设备上。可通过清除扩展数据或卸载 Mu Dashboard 删除。

六、未成年人

本扩展不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

七、政策更新

我们可能不时更新本政策。重大变更可能随扩展更新说明。请定期查阅本页。

八、联系我们

隐私相关问题请发送邮件至 yugakhans@gmail.com，或联系 Chrome Web Store 商品页上的发布者。

九、同意

安装并使用 Mu Dashboard，即表示你同意本隐私政策。若不同意，请勿使用本扩展。

Mu Dashboard shows local system and browser vitals (CPU, memory, storage, displays, and related browser APIs). It is designed to minimize data collection.

1. What we process on your device

  • Metric snapshots used to render the popup and the optional floating HUD
  • Settings: language, refresh interval, floating-panel preferences, optional alert thresholds (chrome.storage.local)
  • Optional unlock status via ExtensionPay: a local paid/email cache may be kept so unlock works offline for a limited TTL. Payment card data is processed by ExtensionPay / its processors — Mu Dashboard does not operate a metrics backend

2. What we do not collect

  • Page content, form data, or website cookies
  • Browsing history, tab titles, or tab URLs
  • Keystrokes or clipboard contents
  • Analytics or advertising identifiers from this extension’s own code
  • Remote font or tracking requests from the extension UI (system fonts only)

3. Permissions

PermissionWhy
system.cpu / system.memory / system.storage / system.displayRead hardware vitals shown in the dashboard
storageSave settings and local unlock cache
alarmsLightweight background warm-up
scripting + optional host accessOnly if you turn on the floating HUD; injects a closed-shadow overlay that does not read the page
notifications (optional)Only if you enable desktop alerts

The floating HUD is off by default. Enabling it triggers Chrome’s permission prompt.

4. Network

  • ExtensionPay (extensionpay.com) only when you open purchase or login
  • No other first-party telemetry endpoints

5. Data storage and your rights

Settings and unlock cache stay on your device via the browser’s local storage API. You can delete them by clearing extension data or uninstalling Mu Dashboard.

6. Children’s privacy

This extension is not directed to children under 13. We do not knowingly collect personal information from children.

7. Changes

We may update this policy from time to time. Significant changes may be noted with extension updates. Please review this page periodically.

8. Contact

For privacy questions, email yugakhans@gmail.com or contact the publisher listed on the Chrome Web Store item page.

9. Consent

By installing and using Mu Dashboard, you agree to this privacy policy. If you do not agree, please do not use the extension.
